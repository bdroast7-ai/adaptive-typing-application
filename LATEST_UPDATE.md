## 🎨 Visual Indicators

### On The Keyboard:

**🟡 Yellow Pulsing Key** = Next key you should press
- The entire key pulses yellow
- Shows you exactly which physical key to press

**🟣 Purple Key** = Key you're currently pressing
- Shows in real-time as you type
- Confirms your keypress is registered

**🔴 Red Highlighted** = Your weak keys (AI detected)
- These are characters you make mistakes on
- Practice more on these!

### In The Typing Area:

**Green text** = Correct ✓
**Red background** = Wrong ✗
**Purple border** = Current position (cursor)
**Gray text** = Not typed yet

## 💡 Pro Tips

### 1. Read the Keyboard
- **Top line** = "This is what I'll get with Shift"
- **Middle line** = "This is what I'll get normally"
- **Bottom line** = "This is the key I need to press"

### 2. Follow the Yellow
The yellow pulsing key tells you exactly what to press next

### 3. Check Middle vs Top
- Most common characters are in the **middle** (normal)
- Less common characters are on **top** (shift)

### 4. Learn Home Row First
```
a → ৃ   s → ু   d → ি   f → া
h → ব   j → ক   k → ত   l → দ
```
These 8 keys cover majority of Bangla typing!

## 🎓 Quick Reference Card

### Most Common Keys:

**Vowel Marks (কার):**
- `f` = া (most common!)
- `d` = ি (very common)
- `s` = ু (common)
- `c` = ে (common)

**Consonants:**
- `j` = ক (ko)
- `k` = ত (to)
- `h` = ব (bo)
- `v` = র (ro)
- `m` = ম (mo)
- `b` = ন (no)
- `l` = দ (do)
- `n` = স (so)

**Special:**
- `g` = ্ (hasant - joins letters)
