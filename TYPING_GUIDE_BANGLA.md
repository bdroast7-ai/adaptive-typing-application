## 🎯 Example: How to Type "পানি" (Water)

### Step by Step:

**Word: পানি**

1. **প** → Press `r` (normal)
   - Look at keyboard: shows প on bottom, ফ on top, key = r

2. **া** → Press `f` (normal)
   - Look at keyboard: shows া on bottom, অ on top, key = f

3. **ন** → Press `b` (normal)
   - Look at keyboard: shows ন on bottom, ণ on top, key = b

4. **ি** → Press `d` (normal)
   - Look at keyboard: shows ি on bottom, ী on top, key = d

**Result: পানি ✓**

### Physical Keys to Press:
```
r + f + b + d = পানি
```

## 📋 Quick Reference - Common Words

### আমি (I/Me)
Need to type the complete word as shown in the practice

### তুমি (You)
- **ত** = `k` (normal)
- **ু** = `s` (normal)  
- **ম** = `m` (normal)
- **ি** = `d` (normal)

**Type: k + s + m + d = তুমি**

### বাংলা (Bangla)
- **ব** = `h` (normal)
- **া** = `f` (normal)
- **ং** = `q` + **Shift** (shift version)
- **ল** = `v` + **Shift** (shift version)
- **া** = `f` (normal)

**Type: h + f + Shift+q + Shift+v + f = বাংলা**

### ভালো (Good)
- **ভ** = `h` + **Shift** (shift version)
- **া** = `f` (normal)
- **ল** = `v` + **Shift** (shift version)
- **ো** = `x` (normal) + `f` (normal)

**Type: Shift+h + f + Shift+v + x + f = ভালো**

## 🎹 Reading the Keyboard

### Each Key Shows 3 Things:

1. **Top (small, gray)** = What you get with **Shift** key
2. **Middle (large, white)** = What you get **normally** (no shift)
3. **Bottom (tiny)** = The **physical key** on your keyboard

## 💡 Tips for Success

### 1. Look at the Virtual Keyboard
- **Yellow pulsing** = Next key you should press
- **Top text** = What Shift gives you
- **Bottom text** = What normal (no shift) gives you

### 2. Practice Common Patterns
Start with simple words:
- মা (ma) = m + f
- না (na) = b + f  
- কি (ki) = j + d
- তা (ta) = k + f

### 3. Learn the Home Row First
```
a → ৃ (rare vowel mark)
s → ু (u mark - very common!)
d → ি (i mark - very common!)
f → া (a mark - MOST common!)
```

### 4. Remember Shift for Aspirated Sounds
- ক (ko) = j
- খ (kho) = **Shift + j**
- ত (to) = k  
- থ (tho) = **Shift + k**

## 🔍 Troubleshooting

### "I'm typing but nothing appears"
✓ Make sure Bijoy keyboard is active on your system
✓ Click the typing area first
✓ Check if you're in Bangla mode (🇧🇩 flag showing)

### "Characters look different"
✓ The app uses standard Bijoy layout
✓ Fonts load automatically (Kalpurush, SolaimanLipi)
✓ Refresh page if fonts don't load

### "Virtual keyboard doesn't match what I type"
✓ Ensure you have Bijoy keyboard active
✓ Some systems use Avro - the layout might differ slightly
✓ Follow the virtual keyboard in the app for accuracy

### "I can't find a character"
✓ Check if it needs Shift key (shown on top of key)
✓ Look at all 4 rows of keyboard
✓ Some rare characters might need special key combinations

## 🎓 Learning Path

### Week 1: Learn the Layout
- Study the virtual keyboard
- Practice typing each character individually
- Focus on home row (a, s, d, f, h, j, k, l)

### Week 2: Simple Words
- Type common 2-3 letter words
- Build muscle memory
- Don't look at physical keyboard

### Week 3: Complex Words
- Practice words with Shift characters
- Learn conjuncts (যুক্তাক্ষর)
- Increase speed gradually

### Week 4+: Speed Building
- Let AI suggest weak keys
- Focus on accuracy (95%+)
- Practice 20-30 minutes daily

## ✨ Pro Tips

1. **Posture**: Sit straight, keep wrists elevated
2. **Touch Typing**: Try not to look at your physical keyboard
3. **Use Virtual Keyboard**: Glance at the screen keyboard instead
4. **Regular Practice**: 15-20 mins daily is better than 2 hours weekly
5. **Accuracy First**: Speed will come naturally with practice
6. **Learn Patterns**: Many words share common character combinations
