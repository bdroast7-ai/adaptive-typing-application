# Quick Start Guide

## 🚀 Get Started in 30 Seconds

### For English Typing
1. **Open the app** - You're already in English mode! 🇺🇸
2. **Click the typing area** - The gray text box in the center
3. **Start typing** - Just begin typing the words you see
4. **Watch your progress** - WPM and Accuracy update in real-time
5. **Complete the test** - Finish all words to see your results
6. **Click "Next Test"** - Continue practicing!

### For Bangla Typing (বাংলা)
1. **Click the language button** (top-right) → Changes to 🇧🇩 বাংলা
2. **Make sure Bijoy keyboard is active** on your system
3. **Click the typing area**
4. **Type using Bijoy layout**:
   - Example: To type "বাংলা"
   - Press: `h` + `f` + `Q` + `V` + `f`
   - You'll see: ব + া + ং + ল + া = বাংলা
5. **Check the virtual keyboard** - It shows which physical key to press!

## 📱 On Mobile

### iOS/Android
1. **Tap the typing area** - Your keyboard appears
2. **Switch to Bangla keyboard** (if typing বাংলা)
   - iOS: Tap 🌐 to switch keyboards
   - Android: Long-press space or use keyboard switcher
3. **Start typing** - It works just like desktop!

## 🎯 Understanding the Colors

### In the Typing Area
- **Gray** = Not typed yet
- **Green** = Correct! ✓
- **Red** = Error - you typed the wrong character ✗
- **Purple line** = Current cursor position (where you're typing)

### On the Virtual Keyboard
- **Yellow (pulsing)** = Next key you should press 👈
- **Purple** = Key you're currently pressing
- **Red highlight** = Your weak keys (need more practice)
- **White** = Normal keys

## 📊 Reading Your Metrics

### WPM (Words Per Minute)
```
42 WPM = You type 42 words per minute
- Beginner: 0-30 WPM
- Intermediate: 30-50 WPM  ← You are here!
- Advanced: 50-80 WPM
- Expert: 80+ WPM
```

### Accuracy
```
95% = 95% of your keystrokes are correct
- Aim for 95%+ for best learning
- Below 90% = Slow down, focus on accuracy
- Above 97% = Try to increase speed!
```

### Time
- Shows how long you've been typing
- Timer starts on first keystroke
- Stops when test is complete

## 🎹 Bijoy Keyboard - Key Mappings

### Most Common Characters You'll Need

#### Vowel Marks (কার)
| Physical Key | Bangla | Example |
|--------------|--------|---------|
| f | া | ক + া = কা |
| d | ি | ক + ি = কি |
| s | ু | ক + ু = কু |
| c | ে | ক + ে = কে |

#### Common Consonants
| Physical Key | Bangla | English Equivalent |
|--------------|--------|-------------------|
| j | ক | k (ko) |
| k | ত | t (to) |
| l | দ | d (do) |
| h | ব | b (bo) |
| v | র | r (ro) |
| m | ম | m (mo) |
| b | ন | n (no) |
| n | স | s (so) |

#### Joining Characters (যুক্তাক্ষর)
| Physical Key | Bangla | Purpose |
|--------------|--------|---------|
| g | ্ | Removes vowel, joins letters |
| z | ্র | Ref (র-ফলা) |

### Example Words to Practice

**আমি** (I/Me):
- No standard mapping, type as displayed

**তুমি** (You):
- k (ত) + s (ু) + m (ম) + d (ি) = তুমি

**বাংলা** (Bangla):
- h (ব) + f (া) + Q (ং) + V (ল) + f (া) = বাংলা

**ভালো** (Good):
- H (ভ) + f (া) + V (ল) + x (ও) = ভালো

Note: Uppercase = Shift key held

## 🎓 Learning Path

### Day 1-3: Build Baseline
- **Goal**: Type 10-15 tests in your chosen language
- **Focus**: Just practice, don't worry about speed
- **Result**: AI learns your typing patterns

### Day 4-7: Targeted Improvement
- **Goal**: Follow AI suggestions
- **What to expect**: "🎯 Focusing on your weak keys: [characters]"
- **Focus**: Pay attention to highlighted weak keys
- **Result**: Accuracy improves on difficult characters

### Week 2+: Speed Building
- **Goal**: Increase WPM while maintaining 95%+ accuracy
- **Focus**: Touch typing (not looking at keyboard)
- **Result**: Noticeable improvement in both speed and accuracy

## ⌨️ Typing Tips

### Posture
✓ Sit straight
✓ Feet flat on floor
✓ Elbows at 90° angle
✓ Wrists slightly elevated

### Technique
✓ Use all 10 fingers
✓ Return to home row (ASDF JKL;)
✓ Don't look at keyboard
✓ Focus on accuracy first, then speed

### Practice Schedule
```
Daily Recommended:
Morning:   10 minutes (warmup)
Afternoon: 15 minutes (focused practice)
Evening:   10 minutes (review weak keys)

Total: 35 minutes/day
Result: Significant improvement in 2-4 weeks!
```

## 🔧 Troubleshooting

### "Text is overflowing the box"
✗ **Not anymore!** - Fixed. Text now wraps properly.

### "Virtual keyboard doesn't match my typing"
- For Bangla: Make sure Bijoy keyboard is active
- For English: Standard QWERTY expected
- Check: Physical key labels shown below Bangla characters

### "AI isn't suggesting weak keys"
- You need at least 5 attempts per character
- Keep practicing - statistics build up over time
- Try completing 5-10 tests first

### "My statistics disappeared"
- Check: Are you in incognito/private mode?
- Solution: Use normal browser mode for persistence
- Data stored in localStorage (browser-specific)

### "Bangla characters look weird"
- Fonts loading from CDN automatically
- Try: Refresh the page
- Ensure: Internet connection active
- Fallback: System fonts will be used

## 🌟 Pro Tips

1. **Accuracy > Speed**: Always prioritize getting it right over going fast
2. **Regular Practice**: 30 mins daily beats 3 hours once a week
3. **Trust the AI**: When it shows weak keys, focus on those characters
4. **Use Virtual Keyboard**: Glance at it to learn key positions
5. **Take Breaks**: Rest your hands every 20-30 minutes
6. **Posture Matters**: Good posture prevents fatigue and injury
7. **Track Progress**: Check your history to see improvement trends
8. **Don't Reset**: Keep building statistics for better AI suggestions
9. **Both Languages**: Practice both if bilingual - builds finger flexibility!
10. **Celebrate Wins**: Beat your previous record? Awesome! 🎉
